# Foundation Decisions Moved

Reusable Web3 foundation decisions hiện nằm tại:

- [`foundation/decisions/README.md`](foundation/decisions/README.md)

Các decision riêng lẻ nằm dưới:

```text
docs/foundation/decisions/
```

Khi repository được phát triển thành một dApp cụ thể, `docs/decisions/` có thể được dùng cho application-specific decisions.

Application decisions không được thay thế hoặc copy foundation decisions.

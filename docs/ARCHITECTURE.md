# Architecture Documentation Moved

Reusable Web3 foundation architecture hiện nằm tại:

- [`foundation/ARCHITECTURE.md`](foundation/ARCHITECTURE.md)

Foundation architecture phải tiếp tục nằm độc lập dưới `docs/foundation/`.
